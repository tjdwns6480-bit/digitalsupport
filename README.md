# Customer Desk

BigQuery 위의 고객 관리 화면입니다. 한 장짜리 HTML 이고 서버가 없습니다.

## 어떻게 동작하나

브라우저가 구글 OAuth 로 로그인해 BigQuery REST API 를 직접 부릅니다.
조회도 입력도 이 화면에서 합니다. 중간에 서버를 두지 않습니다.

- **이 저장소에는 자료가 없습니다.** 숫자는 로그인한 분의 권한으로 그때그때 받아옵니다.
- **프로젝트·데이터셋·클라이언트 ID 를 코드에 두지 않았습니다.** 처음 한 번 넣으면
  그 브라우저에만 남습니다.
- **클라이언트 보안 비밀번호를 쓰지 않습니다.** 브라우저에는 필요하지 않습니다.

권한이 없는 분이 열면 빈 화면입니다.

## 처음 쓸 때

1. Google Cloud 콘솔 → `Google Auth Platform` → `클라이언트` → **웹 애플리케이션**으로 만듭니다.
2. **승인된 JavaScript 원본**에 이 페이지의 주소를 넣습니다.
3. 계정에 `roles/bigquery.jobUser` 와 `roles/bigquery.dataEditor` 를 줍니다.
   보기만 할 분은 뒤엣것을 `dataViewer` 로 둡니다.
4. 화면을 열어 클라이언트 ID · 프로젝트 ID · 데이터셋을 넣고 로그인합니다.

필요한 테이블과 뷰는 별도 SQL 로 만듭니다.
