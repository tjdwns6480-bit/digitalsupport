처음 쓰실 때 준비할 것
  1. 구글 클라우드 콘솔 → Google Auth Platform → 클라이언트 → 웹 애플리케이션으로 만듭니다.
  2. 승인된 JavaScript 원본에 을 넣습니다. 여기까지만 넣습니다. 뒤 경로를 붙이면 구글이 받지 않습니다. (이 화면의 전체 주소는 입니다)
  3. 계정에 roles/bigquery.jobUser와 roles/bigquery.dataEditor를 줍니다. 보기만 하실 분은 뒤엣것을 dataViewer로 둡니다.
  4. 만들어진 클라이언트 ID를 위 칸에 넣습니다. 이 브라우저에만 기억되고 서버로 가지 않습니다. 보안 비밀번호는 넣지 않습니다. 필요하지 않습니다.
